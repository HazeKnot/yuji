# 02 · 产品与功能框架

## 1. 产品形态

| 端 | 载体 | 用户 | 核心作用 |
|---|---|---|---|
| 妈妈端 | 移动 H5（Vue3 + Vant，已定案） | 孕产期女性 | 建档、记录、筛查、内容、社区 |
| 家属端 | 同一 H5 内角色切换 | 伴侣、长辈 | 接收任务、同步知识、看提醒 |
| 机构端 | Web 后台（Vue3 + Element Plus） | 妇幼保健院、月子中心、社区 | 用户分层看板、随访提醒、内容分发 |
| 志愿者端 | H5 轻量页 | 社工、月嫂、心理咨询师 | 接单陪伴、记录跟进 |

> 为什么是 H5：零安装、扫码/点链接即用、无需微信审核上架、开发最快、适合比赛 Demo。
> 已知取舍：无小程序订阅消息，提醒靠站内信 + 浏览器通知（可选短信）；小程序形态列为二期可选（详见 `03` §1.1 与 `08`）。

## 2. 六大功能模块（二期扩展后）

> 一期的 A/B/C/D 继续保留；二期新增 E（私密健康与月事餐饮）与 F（月子调理与育儿教育），
> 并把 D 从"树洞 + 驿站"扩展为真正的社区与机构协作。完整方案见 `09`。

### 模块 A｜我的身体（健康档案）
- 双档案并存：孕产档案 `profile` 服务孕期人群；全周期档案 `wellness_profile` 服务经期/备孕/产后/育儿/更年期，**不强制填写孕周**
- 全周期档案：经期 → 备孕 → 孕期（按孕周）→ 产褥期 → 育儿期 → 更年期
- 关键数据：孕周、体重、血压、血糖、胎动、产检项与报告解读
- 产检日历：按孕周自动生成待办（NT、唐筛、糖耐、大排畸…），可上传报告
- 趋势图：体重/血压曲线 + 参考区间（**只做参考展示，不做判读**）
- 可穿戴接入（远期）：手环睡眠/心率，用于情绪与疲劳信号

### 模块 B｜我的情绪（本项目真正的差异化）
- **30 秒情绪打卡**：1–5 分 + 情绪标签 + 一句话（可选），语音输入列二期
- **标准化量表**：EPDS（已实现）、GAD-7（焦虑）、PSQI（睡眠）按孕周/产后周触发
- **AI 陪伴对话**：非评判式倾听 + 情绪命名 + 认知重构引导，**不做诊断、不给用药建议**
- **风险分级引擎**：绿（自助内容）/ 黄（志愿者或咨询师人工跟进 + 工单）/ 红（一键转介：合作医院、心理热线；EPDS 第 10 题阳性直接红档）
- **情绪周报**：给用户看"你这周的状态曲线"，给家属端发"她最近可能比较累"

### 模块 C｜我们的家（家庭协同）
- **任务包**：系统按阶段生成可分配任务（如产后第 1 周：夜间喂奶轮班、伤口护理提醒、访客管理）
- **知识同步**：同一篇科普同时推给妈妈和爸爸，避免"育儿理念打架"
- **冲突话术库**：按场景（婆媳喂养分歧、伴侣不作为）给具体句式，不讲大道理
- **感谢卡**：低成本情感反馈机制，提升家属端留存（这个小心思评委很喜欢）

### 模块 D｜她社区 / 她公益
- 五类分区：经验分享、难言之隐、月子日记、育儿互助、心理树洞；支持匿名发帖
- 专业资源撮合：哺乳顾问、月嫂、心理咨询师（可做佣金，但**不做医疗推荐排名**）
- 危机词与导流词自动转人工审核，不直接删除求助帖
- 公益板块：低收入用户申请免费服务包；志愿者时长记录；企业/基金会捐赠入口
- **她驿站**：线下合作点位地图（社区中心、母婴室、妇幼保健院）

### 模块 E｜私密健康与月事餐饮（二期新增）
- **私密健康咨询**：9 张审核知识卡（分泌物、瘙痒、月经不调、痛经、乳房、盆底、避孕、HPV/TCT、更年期）
- 结构化回答：可以这样理解 → 可以先做 → 必须尽快就医的信号 → 日常护理 → 建议科室 → 内容来源
- 风险词升级 + 一键转介 + 就诊准备卡；**不做诊断、不开药、不替代面诊**
- **月事餐饮规划**：按经期 / 卵泡期 / 排卵期 / 黄体期生成一周食谱、营养重点与购物清单
- 没有周期记录时退化为均衡食谱；贫血、妊娠糖尿病、食物过敏提示遵医嘱

### 模块 F｜月子调理与育儿教育（二期新增）
- **42 天月子清单**：饮食、伤口/恶露观察、喂养、盆底唤醒、情绪打卡、避孕、产后复查
- 今日任务 + 接下来 + 全清单三层结构，完成率可视化
- **按月龄育儿课**：新生儿护理、母乳喂养、睡眠、辅食、语言情绪、如厕训练，每节 5 分钟
- 课程与任务都带来源、审核方和"何时需要就医"的边界

## 3. 核心用户旅程（Demo 就演示这一条）

```
扫码进入 → 3 步建档（身份/孕周/关注点）
   → 生成个人首页（今日 3 件事）
   → 情绪打卡（10 秒）
   → 系统识别连续 5 天低落 → 触发 EPDS 量表
   → 得分落入黄档 → 生成"陪伴方案"并通知志愿者
   → 家属端收到"她最近需要支持" → 领取 3 个任务
   → 一周后生成"家庭周报"（妈妈状态↑、任务完成率 80%）
```

这条链路覆盖了：数据采集 → AI 判断 → 人工干预 → 家庭协同 → 效果反馈，**闭环完整**。答辩时只讲这一条，别贪多。

## 4. MVP 边界（第一期做什么 / 明确不做什么）

**做（一期已交付 + 二期已实现）**
1. 【B】建档 + 孕周计算 + 产检日历 + 指标记录 + 报告上传 + 趋势图
2. 【C】家属端任务包（3–5 套模板）+ 知识同步 + 字段级权限
3. 【D】匿名树洞 + 她驿站列表 + 公益申请（轻量实现）
4. 【A】情绪打卡 + EPDS 量表 + 规则三级分级 + 工单
5. 【E】全周期档案 + 周期记录与预测 + 月事餐饮 + 私密健康咨询（知识卡分诊 + 转介）
6. 【F】42 天月子清单 + 按月龄育儿课 + 合作机构与预约线索
7. 内容库 30 篇 + 9 张私密知识卡 + 6 门育儿课（全部标注来源）
8. 机构端从"看板"扩展为五个工作台：全周期看板、合作机构、预约线索、风险跟进、社区审核

> A 是核心差异化；E 是把用户生命周期从 12 个月拉长到 30 年的关键；F 是把建议变成行动。
> 进度告急时的砍单顺序：社区运营 → LLM 对话 → 内容篇数，**永远不砍 A 与 E 的转介链路**。

**不做（并要在答辩中主动说明"我们知道边界在哪"）**
- 不做在线问诊、不开处方、不做影像判读
- 不做电商（不碰药品与供应链，避免变成带货）
- 不做"AI 诊断"：私密咨询只做健康教育与就诊准备
- 不做重社区补贴：社区冷启动靠"机构 + 社群"导入，不烧钱买量

> 主动说明"我们不做什么"，是成熟度的信号，比吹功能全更能加分。

## 6. 交互与文案原则（这是产品气质，也是评审感受）

1. **低负担**：任何一次记录 ≤ 30 秒；不设连续打卡惩罚，断签不清零。
2. **不制造焦虑**：不做"你再不补就晚了"式文案；风险提示必须配"下一步怎么做"。
3. **非诊断话术**：说"这可能是值得关注的信号，我们可以帮你联系专业的人"，不说"你有抑郁倾向"。
4. **默认温柔**：所有空状态、加载态、错误提示都写成安慰句而非系统句。
5. **可退出**：任何环节允许"我现在不想说"，并保留退路。

## 7. 与"母爱"主题的衔接（别把项目做成纯工具）

比赛主题含"母爱"，需要一条**情感叙事线**，但不能煽情到失真。三个抓手：

- **"给未来的一封信"**：孕期写给产后自己的信，产后 42 天解锁。低开发成本，高传播性，Demo 现场效果极好。
- **"她的第一张照片"**：记录母亲本人（而非宝宝）在每个阶段的样子，反转发圈习惯。
- **"妈妈也需要被夸"**：家属端每天收到一条"今天可以这样夸她"的提示。

这三个功能成本极低，但是路演的**情绪爆点**，建议至少做第一个。
