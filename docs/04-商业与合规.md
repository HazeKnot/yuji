# 04 · 商业模式与合规

## 1. 商业模式画布（精简版）

| 模块 | 内容 |
|---|---|
| 客户细分 | C 端：孕产期女性（核心）、伴侣、长辈；B 端：妇幼保健院、月子中心、母婴门店、企业工会 |
| 价值主张 | C 端：被看见、被支持、少焦虑；B 端：低成本获客 + 随访效率 + 服务差异化 |
| 渠道 | 医院/社区扫码、月子中心合作、母婴门店、社群、校园/工会 |
| 收入来源 | C 端会员订阅、B 端 SaaS 年费、服务撮合佣金、政府购买/公益基金 |
| 关键资源 | 权威内容库、风险分级模型、线下机构网络、志愿者体系 |
| 关键活动 | 内容运营、人工跟进（黄档）、机构 BD、合规管理 |
| 关键伙伴 | 妇幼保健机构、心理咨询机构、月嫂培训学校、公益基金会、高校 |
| 成本结构 | 研发、内容与医学审核、人工跟进人力、获客、合规与安全 |

## 2. 收入结构（按"先易后难"排序）

1. **B 端 SaaS（最现实）**
   月子中心/社区医院按点位付费，提供随访看板、内容分发、客户满意度工具。
   定价建议：中小机构 3000–8000 元/年/点位（价格需在 BP 中说明测算逻辑与可比参照）。
2. **C 端会员（中期）**
   免费：建档、打卡、基础内容、量表。
   会员（如 19–29 元/月）：个性化方案、家属端完整功能、专家课程、优先人工陪伴。
3. **服务撮合佣金（后期）**
   哺乳顾问、产后康复、心理咨询，抽佣 10%–20%。**不做医疗项目排名竞价**。
4. **政府购买 / 公益基金（叙事重点）**
   承接社区妇幼健康促进、优生优育宣传、心理健康科普等项目。这一块现金流慢，但对"社会价值"评分极关键。

> 财务预测写作纪律：给出**假设 → 推导 → 结果**三步，不要只甩一张漂亮曲线。评委问"这个数怎么来的"必须答得出。

## 3. 单位经济模型（示意，需你用真实假设替换）

| 指标 | 说明 |
|---|---|
| CAC（单用户获客成本） | 医院/社区扫码导入 ≈ 极低；线上投放较高。**这是选择线下渠道的核心理由** |
| 付费转化率 | 参照工具类订阅产品常见区间，需标注来源或说明为"试点期实测" |
| ARPPU | 会员月费 × 平均订阅月数 |
| LTV / CAC | 目标 > 3，BP 中必须给出算式 |
| 黄档人工成本 | 单次跟进时长 × 人力成本，是最大的变动成本，需专门测算 |

**关键洞察**：本项目最大的成本不是服务器，是**黄档人工跟进**。所以模式设计上必须"绿档占绝大多数、黄档靠志愿者+机构承接"，否则规模越大越亏。这一点在答辩中主动讲出来，非常加分。

## 4. 冷启动路径（单点打透，别一上来全国）

**第一阶段（0–6 月）：一城一院一社区**
- 选 1 家妇幼保健院 + 1 个社区卫生服务中心做试点
- 目标：建档 300–500 人，黄档干预 20–30 例，形成 1 份可公开的效果报告
- 关键动作：护士站放二维码、产后访视时同步推荐、给医生一个"看板"作为交换

**第二阶段（6–12 月）：复制到 1 个区 + 3–5 家月子中心**
**第三阶段（12 月+）：县域下沉 + 公益合作**

> 校赛阶段不需要真的跑通三阶段，但必须证明**第一阶段已经在动**（有试点意向书、有用户访谈、有 Demo 数据）。

## 5. 合规红线（这一节比商业模式更重要）

### 5.1 医疗边界
- ❌ 不做在线诊断、不开处方、不做影像/检验结果判读、不推荐具体药品与剂量
- ✅ 做健康科普、健康教育、风险筛查（标准化量表）、就医引导与转介
- 若未来涉及互联网诊疗，需取得《医疗机构执业许可证》并按规定进行互联网诊疗备案——**明确写在"未来规划"而非"现有能力"里**

### 5.2 数据合规
- 健康信息属《个人信息保护法》中的**敏感个人信息**，需**单独同意**、告知必要性与影响
- 遵循最小必要原则；提供查阅、复制、更正、删除、撤回同意的通道
- 家属端数据共享必须由用户**逐项授权**，默认不可见
- 未成年人信息（如涉及青少年女性健康）需监护人同意
- 数据出境、第三方 SDK 共享需单独披露

### 5.3 内容与广告
- 母婴类内容与广告受《广告法》《互联网广告管理办法》约束，保健食品、医疗器械、药品广告有严格限制
- **不做焦虑营销**：不制造"错过关键期"的恐惧感，这既是伦理也是品牌资产
- 所有科普内容标注来源与审核人（医学顾问）

### 5.4 AI 合规
- 生成内容需显著标识"AI 生成/辅助"
- 建立内容审核与投诉通道
- 按《生成式人工智能服务管理暂行办法》评估备案义务

### 5.5 伦理守则（建议写成一页放进 BP 附录）
1. 不诊断、不替代医生
2. 不评判母亲的选择（母乳/奶粉、顺产/剖宫产、全职/职场）
3. 不制造焦虑、不利用脆弱时刻营销
4. 危机情况优先转介，不追求留存
5. 用户可随时删除全部数据并退出

> 这一页在评审中往往是**差异化得分点**：大部分学生项目只讲增长，讲伦理的很少。

## 6. 社会效益指标（写进 BP 的"社会价值"章）

| 维度 | 指标 | 目标（试点期示例） |
|---|---|---|
| 覆盖 | 建档用户数、县域用户占比 | 500 人 / ≥30% |
| 筛查 | 情绪量表完成率、产后 42 天内筛查覆盖率 | ≥60% / ≥50% |
| 干预 | 黄档 48h 内联系率、红档转介成功率 | ≥90% / ≥80% |
| 家庭 | 家属端绑定率、任务周完成率 | ≥40% / ≥60% |
| 能力 | 培训志愿者人数、合作机构数 | 30 人 / 5 家 |
| 公平 | 公益名额使用数、低收入用户占比 | 50 个 / ≥20% |

## 7. 一页纸风险表（答辩备用）

| 风险 | 等级 | 缓解 |
|---|---|---|
| 医疗合规风险 | 高 | 只做筛查与转介，医学顾问审核，法务文本预置 |
| 数据泄露 | 高 | 加密、最小权限、审计、渗透测试 |
| 大厂竞争 | 中 | 不与大厂拼流量，做"机构 + 家庭协同"的深水区 |
| 用户留存低 | 中 | 家属端与任务机制提升粘性；内容节奏化推送 |
| 黄档人力成本失控 | 中 | 志愿者体系 + 机构承接 + 绿档自助分流 |
| 团队持续性 | 中 | 依托高校实验室/社团，形成传承机制 |
