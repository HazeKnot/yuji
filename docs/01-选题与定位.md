# 01 · 选题分析与定位

## 1. 为什么这个赛道值得做

### 政策面（这是"能讲给评委听"的合法性来源）

- 《"健康中国 2030"规划纲要》明确设置**妇幼健康**相关指标与专项行动。
- 国家层面持续推进**生育支持政策体系**建设，各地出台育儿补贴、托育服务、生育友好型职场等配套措施。
- 《母婴安全行动提升计划》《健康儿童行动提升计划》对孕产期保健、产后访视、儿童早期发展提出明确要求。
- 教育部/卫健委推动**学生心理健康与女性健康科普**进校园。

> 写作要求：BP 中引用政策必须写全**文件名 + 发布单位 + 年份**，并说明"我们做的事对应哪一条"。不要只堆政策名。

### 社会面（这是"能打动评委"的情感来源）

1. **生育率下降，但单胎投入上升**——家庭对孕产质量的要求在提高，愿意为"专业 + 安心"付费。
2. **初婚初育年龄推迟**，高龄产妇比例上升，孕期并发症与心理压力同步上升。
3. **家庭结构小型化**，传统"长辈带娃经验"失灵，新手父母处于"无经验 + 无支持"的双重真空。
4. **产后心理健康长期被忽视**：国内多项研究报道产后抑郁检出率处于较高水平（写作时须引用具体文献、样本与年份，不要凭印象写数字），而**筛查率低、病耻感强、专业资源集中在大城市**，这构成一个真实且急迫的缺口。

## 2. 竞品拆解：行业的结构性缺口在哪

| 产品/类型 | 核心定位 | 优势 | 缺口（我们的机会） |
|---|---|---|---|
| 宝宝树孕育 / 妈妈网孕育 | 社区 + 工具 + 电商 | 流量大、内容丰富、社区活跃 | **宝宝视角**、广告与带货混杂、心理支持薄弱 |
| 丁香妈妈 | 专业科普 + 知识付费 | 内容权威、医生背书 | 单向输出、无长期陪伴、无家庭协同 |
| 育学园 | 育儿记录 + 知识 | 记录细致、数据化 | 只记宝宝，母亲自身健康与情绪基本缺席 |
| 小豆苗 | 疫苗接种提醒 | 刚需、高频、覆盖广 | 单点工具，无延伸价值 |
| 综合心理咨询平台 | 专业咨询 | 有资质、可转介 | 价格高、非孕产垂直、无连续性陪伴 |
| 医院/妇幼公众号 | 院内挂号与通知 | 权威、强信任 | 体验差、**出院即断联**、无日常陪伴 |
| 小红书/抖音母婴内容 | 内容社区 | 真实感、共鸣强 | 信息噪声大、**焦虑营销**严重、无专业分层 |

**结论：整个行业把"母亲"当成"育儿的执行者"，而不是"需要被照护的人"。**
这是一个不在功能层而在**视角层**的空白——恰好是创新比赛最看重的"重新定义问题"。

## 3. 三类真痛点（访谈要验证的假设）

### 痛点 A：信息焦虑 → 决策瘫痪
- 现象：同一问题搜到 5 种说法，越查越慌；产检单看不懂；不知道该不该补、该不该忌口。
- 本质：**不是缺信息，是缺"针对我的情况的、可执行的下一步"**。
- 我们的解法：基于个人档案（孕周、指标、既往史）+ 权威指南的**个性化行动清单**，一次只给 3 件事。

### 痛点 B：情绪黑洞 → 没人问"你还好吗"
- 现象：所有人的关心都指向宝宝；母亲的情绪波动被归因为"矫情""激素""想太多"。
- 本质：**缺乏低成本、无病耻感的情绪出口 + 缺乏客观筛查与转介路径**。
- 我们的解法：30 秒情绪打卡 + 定期量表筛查 + 红黄绿分级 + 人工/机构转介，全程不说"你有病"。

### 痛点 C：家庭协作断裂 → "丧偶式育儿"
- 现象：育儿责任高度集中在母亲；长辈经验与科学育儿冲突；伴侣"想帮但不知道帮什么"。
- 本质：**信息不对称 + 责任边界模糊**，不是态度问题而是**协作工具缺失**。
- 我们的解法：家属端任务包（"今晚你负责这三件事"）+ 知识同步（同一份科普同时推给妈妈和爸爸）+ 冲突话术库。

> 访谈提纲建议：不要问"你会用吗"，要问"上一次你为这件事焦虑是什么时候，当时你做了什么"。行为回忆比意愿表达可信 10 倍。

## 4. 用户画像

**画像 1｜林晓，29 岁，孕 24 周，互联网运营**
- 场景：上班摸鱼查资料，半夜因为一个指标睡不着。
- 诉求：别再给我 100 篇文章，告诉我今天该做什么。
- 付费意愿：中等，愿为"安心"付月费。

**画像 2｜周敏，31 岁，产后 3 个月，全职带娃**
- 场景：全天候育儿，社交断裂，情绪低落但不敢说。
- 诉求：有人听我说话；有人替我做一顿饭/看一小时孩子；不想被评判。
- 付费意愿：低（对价格敏感），靠公益/社区资源承接。

**画像 3｜陈磊，33 岁，新手爸爸**
- 场景：想帮忙但总被说"帮倒忙"。
- 诉求：给我明确的、可执行的任务清单和标准。
- 付费意愿：高（愿意为"减少家庭矛盾"付费）。

> 三个画像分别对应产品的三条主线：**妈妈端效率、妈妈端情绪、家属端协作**。路演时讲这三个人的故事，比讲市场规模有效。

## 5. 定位与价值主张

**定位句（对内）**
> 面向孕产期女性的、以母亲为主体的健康管理与家庭协作支持平台。

**价值主张（对外，三种长度）**

- 电梯版（15 秒）：*"母婴 App 都在教你怎么带孩子，我们想先照顾好那个带孩子的人。"*
- 一句话版：*把妈妈的身体、情绪和家庭支持，装进一个每天只要 3 分钟的小程序。*
- 完整版：*育己以母亲为中心，整合孕产期健康档案、情绪风险筛查与家庭协作工具，通过 AI 分级预警与线下机构转介，让每一位女性在成为母亲的过程中，不被忽略、不被独自承担。*

**差异化三角（画在 PPT 上）**
```
        母亲主体性
           /\
          /  \
  家庭协同 ---- 分级转介
```
竞品通常只占一个角，我们占三个角的交集。

## 6. 社会价值（评委很吃这一块，但要说人话）

- **可量化**：服务人次、筛查覆盖率、黄档干预转介率、家属端任务完成率、县域覆盖点位数。
- **可讲述**：一个产后情绪低落的妈妈，通过黄档预警被志愿者联系上，最终转介到社区医院——一个具体故事胜过十个百分比。
- **可延展**：模式可复制到更年期女性健康、慢病家庭照护、罕见病家庭支持。

## 7. 选题风险自检

| 风险 | 说明 | 应对 |
|---|---|---|
| 赛道过热 | 母婴赛道参赛项目多，容易同质化 | 用"母亲主体性"这一视角差异立住，功能上不与大厂拼全 |
| 合规敏感 | 健康数据 + 心理筛查 | 严格"筛查不诊断"，见 04 文档 |
| 数据难获取 | 拿不到行业报告 | 用公开统计年鉴 + 小样本自采访谈，坦诚说明样本量 |
| 落地性被质疑 | 只有 App 没有场景 | 绑定 1–2 家社区医院/月子中心做试点，拿意向书 |
