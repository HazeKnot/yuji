# 05 · 比赛材料与路演

## 1. 参赛材料清单

| 材料 | 用途 | 篇幅建议 |
|---|---|---|
| 商业计划书（BP） | 网评/初审 | 15–25 页 PDF，图表为主 |
| 路演 PPT | 现场答辩 | 12–15 页 |
| 产品 Demo | 现场演示 / 视频 | 90 秒视频 + 可上手小程序 |
| 用户调研报告 | 佐证 | 附录，10 页 |
| 合作意向书 | 可行性论证 | 1–3 份，盖章或聊天记录截图 |
| 财务测算表 | 商业模式 | Excel 附录 |
| 知识产权/合规说明 | 加分 | 软著申请受理号、隐私政策文本 |

## 2. 商业计划书目录（12 章）

1. **项目摘要**（一页讲完：问题—方案—差异化—进展—团队）
2. **背景与机会**：政策依据、社会变迁、行业规模与增长（**必须标源**）
3. **问题定义**：三类痛点 + 用户原话引用 + 访谈样本说明
4. **竞品分析**：对比表 + 一张定位图（母亲主体性 × 家庭协同）
5. **产品与解决方案**：四大模块、核心旅程图、界面截图
6. **核心创新点**：四条，每条配"为什么别人做不到/没做"
7. **技术方案**：架构图、AI 分级机制、安全护栏（图示优先）
8. **商业模式**：画布、收入结构、单位经济、定价逻辑
9. **市场与推广**：单点打透策略、渠道、试点进展
10. **团队**：能力矩阵（技术/医学/设计/运营），顾问（医学、心理）
11. **社会价值与伦理**：效益指标 + 伦理守则一页
12. **发展规划与融资**：三阶段路线图、资金用途

> 写作纪律：**每页只讲一件事，每张图只有一个结论**。评委看 BP 平均每页不到 20 秒。

## 4. 5 分钟路演逐字稿框架

| 时间 | 内容 | 要点 |
|---|---|---|
| 0:00–0:30 | 钩子 | 讲那个"没人问她好不好"的故事，别自我介绍 |
| 0:30–1:20 | 问题 | 三类痛点，每类一句人话 + 一个数字 |
| 1:20–2:00 | 洞察 | "行业把母亲当工具人"——这是我们的重新定义 |
| 2:00–3:10 | 产品 Demo | 现场演示核心旅程（或播 60 秒视频） |
| 3:10–4:00 | 差异化 + 壁垒 | 分级转介、家庭协同、机构网络 |
| 4:00–4:30 | 进展 | 访谈人数、试点机构、用户数、意向书 |
| 4:30–5:00 | 团队 + 愿景 | 一句话收尾，回到 slogan |

**演讲技巧**
- 第一句不要念 PPT，讲一个具体的人。
- 所有数字只说 3 个，多了记不住。
- 结尾把 slogan 再说一遍，形成记忆锚点。

## 5. Demo 演示脚本（90 秒）

```
00:00  扫码进入 → "我们假设我是孕 28 周的小林"
00:10  首页：孕周 28+3，今日三件事（补铁、数胎动、产检提醒）
00:25  情绪打卡：选一个"有点累"的表情，语音说一句"今天有点撑不住"
00:40  系统提示：连续 5 天低落，建议做个 3 分钟评估 → EPDS
01:00  结果：得分落在"需要关注"区间 → 不贴标签，直接给三个行动按钮
01:10  一键通知志愿者 / 一键联系社区医院
01:20  切到家属端：伴侣收到"她最近需要支持"，领取任务"今晚 10 点前接手一次夜奶"
01:35  打开"给未来的一封信"，读出孕期写下的那句
01:50  收尾：这就是我们想做的事——先照顾好那个当妈妈的人
```

> 现场务必准备：手机 2 台（妈妈端 + 家属端）、录屏视频兜底、演示专用账号、充电宝、离线可用的关键页面。

## 6. 评委高频质疑 & 应答

| 质疑 | 应答要点 |
|---|---|
| "这和大厂母婴 App 有什么区别？" | 视角差异（母亲主体）+ 结构差异（家庭协同端）+ 场景差异（机构内嵌，不做流量生意） |
| "你们有什么壁垒？" | 不是算法壁垒，是**机构网络 + 医学内容审核体系 + 风险分级流程**三重运营壁垒，越下沉越难被替代 |
| "涉及医疗，合规怎么做？" | 明确只做筛查与转介，不做诊断；量表用公开标准版；医学顾问审核；数据单独同意 + 最小必要 |
| "用户凭什么付费？" | 先付钱的是 B 端（机构要随访效率和差异化服务），C 端免费获客，会员是后置变现 |
| "AI 会不会乱说？" | AI 只做初筛与内容改写，黄红档强制人工；有输入/生成/输出三层护栏 |
| "怎么赚钱？规模多大？" | 给出假设—推导—结果三段式，坦言试点期数据，不吹大数 |
| "你们能做出来吗？" | 现场给 Demo + 两周开发排期 + 已有试点意向 |
| "团队缺医学背景怎么办？" | 已聘/拟聘医学与心理顾问，列出姓名与单位；高校附属医院资源 |
| "公益部分是不是作秀？" | 给出公益名额使用数据、志愿者时长记录、县域覆盖计划 |
| "如果大厂抄你们呢？" | 大厂做不了"低毛利 + 重线下 + 强合规"的活；我们的护城河是"愿意做脏活" |

## 8. 答辩现场纪律

1. 不背稿，讲人话；卡壳就说"这个问题我们考虑过，目前的做法是……"
2. 不会的问题不要编，答"这一块是我们下一阶段的重点，目前的初步想法是……"
3. 被质疑时先接住："您说的这个问题确实存在"，再给方案，不辩解。
4. 队友分工明确：主讲、技术、商业、演示各一人，别抢话。
5. 计时器响就停，超时是硬伤。
